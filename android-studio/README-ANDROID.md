# Android Studio'da Açma

Bu klasör Android Studio projesidir. Uygulama, `WebView` ile `app/src/main/assets/www/index.html` dosyasını açar.

## Adımlar

1. Android Studio'yu aç.
2. `Open` seçeneğine bas.
3. Bu klasörü seç:
   `android-studio`
4. Gradle senkronizasyonunun bitmesini bekle.
5. Üst taraftan bir emulator veya bağlı telefon seç.
6. Yeşil `Run` düğmesine bas.

## Web Kodları Nerede?

Uygulamanın HTML, CSS ve JavaScript dosyaları burada:

`app/src/main/assets/www`

Android tarafındaki ana dosya:

`app/src/main/java/com/example/mevsimgidarehberi/MainActivity.java`
